# Storage Interfaces

- [Bulk Storage Interface](bulk_storage_interface.md) binds one cell.
- [Advanced Bulk Storage Interface](advanced_bulk_storage_interface.md) binds up to 16 cells and supports per-face access, redstone control and a secondary filter.
