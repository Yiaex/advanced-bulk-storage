# ME Advanced Cell Workbench

Open normally to install upgrade cards or edit AE2 partitions. With a bulk cell installed, sneak and use with an empty hand to open the unified filter and inventory editor. Use a named name tag on the block to rename the cell.

In the cell editor, Shift-click **Copy** to export the filter, limits and auto-sort setting together. Shift-click **Paste** on another cell to import them. The editor validates the target cell and its installed upgrades. Importing a new disposal rule requires a second confirmation. Upgrades, inventory, UUID and discard history stay with their original cell.
