# 统一过滤编辑器

手持元件右键打开。编辑草稿后点击**保存**，服务器会检查设备权限和规则。**关闭**会放弃上次有效保存之后的修改。

| 语法 | 含义 |
| --- | --- |
| `#c:ingots` | 指定已注册的物品标签 |
| `@ae2` | 匹配指定注册命名空间的物品 |
| `minecraft:iron_ingot` | 匹配指定注册名的所有数据组件变体 |
| `#c:ingots/*` | 匹配已注册的金属锭细分标签 |
| `!`、`&`、`\|`、`(…)` | 非、与、或和分组 |

每个可成立的白名单分支都必须有明确的正向条件。例如 `#c:ingots & !#c:ingots/iron` 匹配铁锭以外的金属锭。规则为空、引用标签缺失或旧规则失效时暂停接收，已存物品仍可提取。

从 JEI 拖入物品到 **+** 槽位即可反查，也可以在光标持物时点击该槽。结果会按元件权限显示主要标签、细分标签、精确物品 ID 及所属模组。**预览**显示草稿匹配的品种。**库存**只显示当前元件的实存物品，悬停可读到完整数量。

**加收藏**使用搜索框文字作为可选标题，保存当前草稿。**历史**显示最近保存的规则。**复制**和**粘贴**可以交换规则文本。宽泛规则会排除装备，精确装备 ID 受元件权限和服务端设置约束。

默认限制为 1,024 字符、16 层嵌套、128 个条件。界面显示当前元件和[扩展标签卡](extended_tag_card.md)允许的标签数。数据包和 KubeJS 可提供标签，服务器重载后会重新核验规则。
