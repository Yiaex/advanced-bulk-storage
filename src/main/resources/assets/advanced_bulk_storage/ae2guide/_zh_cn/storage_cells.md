# 大宗存储元件

| 存储元件 | 本次制作消耗的材料 |
| --- | --- |
| [标签大宗存储元件](tag_bulk_storage_cell.md) | 空白 MEGA 大宗物品存储元件、逻辑处理器、工程处理器和 1 枚 64M 存储组件 |
| [高级标签大宗存储元件](advanced_tag_bulk_storage_cell.md) | 工程处理器和 1 枚 256M 存储组件 |
| [模组大宗存储元件](mod_bulk_storage_cell.md) | 1 枚 64M 存储组件和 1 枚 256M 存储组件 |
| [量子大宗存储元件](quantum_bulk_storage_cell.md) | 2 枚 256M 存储组件 |

在工作台制作第一级。之后把上一阶元件放入锻造台升级，库存和配置会随盘保留。[统一过滤编辑器](filter_editor.md)说明各级盘可使用的规则。
