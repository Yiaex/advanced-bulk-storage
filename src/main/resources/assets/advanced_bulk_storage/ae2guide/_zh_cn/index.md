# MEGA Cells：高级大宗存储

一张大宗元件可独立记录多种物品的库存。即使注册名相同，名称、附魔、损耗或其他数据组件不同的物品也会各占一个库存条目。

1. 使用空白 MEGA 大宗物品存储元件、64M 存储组件、逻辑处理器和工程处理器，制作[标签大宗盘](tag_bulk_storage_cell.md)。
2. 手持新元件右键，在[统一过滤编辑器](filter_editor.md)选择**金属锭**预设。
3. 保存规则，将元件装入在线的 ME 驱动器。在 ME 存储终端存入铁锭、金锭和铜锭。
4. 如需精确物品分区或安装[扩展标签卡](extended_tag_card.md)，使用 AE2 元件工作台。

盘内数量使用任意精度整数。AE2 的可见数量和单次存取受有符号 long 范围限制。
