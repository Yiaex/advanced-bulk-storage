# 扩展标签卡

在 AE2 元件工作台安装，每张高级大宗存储元件最多一张。安装后解锁全部过滤语法。

普通等级装卡后默认可配置 64 个标签，量子等级可配置 128 个。移除卡后库存与表达式会保留。若表达式超出当前权限，暂停接收，已有库存仍可取出。
