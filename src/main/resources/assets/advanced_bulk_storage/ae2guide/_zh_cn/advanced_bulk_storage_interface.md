# ME 高级大宗存储接口

连接正常供电且有频道的 AE2 网络。接口占用 1 个频道，基础耗电 16 AE/t，可绑定最多 16 张大宗盘。

按盘名、类型、驱动器坐标或过滤规则搜索。同类盘可通过自定义名称及槽位区分。切换到 **已绑定** 查看当前选盘，用滚轮或滚动条浏览。点击条目逐张绑定或解绑。选中行上的数字表示访问顺序，点击数字可将该盘调到第一位。离线绑定可以单独解除。

将鼠标停在盘图标或条目上预览库存。按住 **Shift** 展开更多真实库存，并查看该盘的过滤规则和当前访问权限。资源池按基础单位显示，各种可提取的压缩形式共用库存。预览可显示超过有符号 long 范围的盘内数量，外部批量访问每种物品最多可见 2,147,483,647 件。

切换面后设置独立的存取权限。通过 **二次白名单** 打开统一过滤编辑器。留空时沿用目标盘自身的入库规则。红石按钮可选择需要信号、无信号或忽略信号。

接口禁止通过相邻 ME 存储总线重新挂载，以避免重复统计及访问回环。
