# Multi-Compression Card

Install one in any of this addon's bulk cells using the AE2 Cell Workbench. Each verified reversible recipe chain gets one pool. The actual input form must satisfy the cell's whitelist.

For example, 9 iron nuggets are equivalent to 1 ingot and 81 nuggets to 1 block. Extracting any form deducts from the same base-unit balance. The ME display and hover card show base units once. The bulk interface batch capability can address alternative forms by item key. Capacity is measured in base units up to the configured per-key LONG cap.

Existing standalone stock is preserved. If the card is removed or a recipe changes, the original base units can still be withdrawn. Conversion resumes only when the current chain matches the stored ratios.
