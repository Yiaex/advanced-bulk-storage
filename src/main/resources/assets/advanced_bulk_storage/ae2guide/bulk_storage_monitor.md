# ME Bulk Storage Monitor

Connect to an online ME network (one channel, 4 AE/t). Choose a metric and a target if required. Network item, tag or namespace totals use AE2 stock notifications. One-cell mode tracks actual stored base units and can use an optional whitelist. Type usage is measured in thousandths (1000 equals 100%). Other modes show the most recent sorting or migration throughput, whether a limit is reached, or the cumulative discarded count. Choose a comparison and threshold to emit redstone power 15 while a reading matches. An unavailable target suspends the output.
