# ME Bulk Storage Manager

Connect to an online ME network (one channel, 4 AE/t). Search by name, UUID, location, or filter. Narrow results by tier or state and sort by location, name, or occupied types. Select a row to inspect live inventory, then choose **Details** for upgrades, priority, energy use, bound interfaces, compression pools and disposal history. A star marks a pool measured in base units. The manager sends one page at a time.

To apply a whitelist, rejection limit or auto-sort setting, select a cell or arm **Select page**, choose an operation and press **Apply**. The server checks each target and displays how many were updated. Page selection covers only the rows shown. The cell editor is used to confirm destructive overflow rules.
