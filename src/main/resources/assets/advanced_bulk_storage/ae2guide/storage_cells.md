# Storage Cells

| Storage cell | Ingredients added at this step |
| --- | --- |
| [Tag Bulk Storage Cell](tag_bulk_storage_cell.md) | Blank MEGA Bulk Item Storage Cell, logic processor, engineering processor, 64M Storage Component |
| [Advanced Tag Bulk Storage Cell](advanced_tag_bulk_storage_cell.md) | Engineering processor and 256M Storage Component |
| [Mod Bulk Storage Cell](mod_bulk_storage_cell.md) | 64M Storage Component and 256M Storage Component |
| [Quantum Bulk Storage Cell](quantum_bulk_storage_cell.md) | Two 256M Storage Components |

Craft the first cell at a crafting table. Upgrade the previous tier at a smithing table to carry its inventory and settings forward. [Unified Filter Editor](filter_editor.md) explains the rules that each tier supports.
