# ME Bulk Storage Drive

Accepts 32 bulk cells by default and draws 4 AE/t plus each installed cell's draw. One channel is required. Supports this addon's cells and the MEGA Cells bulk item cell. Set the AE2 mount priority in the menu. This addon's cells can be bound to a bulk interface on the same grid.
