# Extended Tag Card

Install at most one card per Advanced Bulk Storage cell in an AE2 Cell Workbench. This unlocks every filter operator.

The default limit rises to 64 tags for the first three tiers and 128 for the quantum tier. Removing the card preserves the rule and inventory. If the rule exceeds the current permissions, the cell pauses insertion while continuing to allow extraction.
